# Prompt Examples

These prompts can be used directly in Codex.

## Planning Only (No Image Generation)

```text
Use $abidemi-illustrations to analyze where this article needs illustrations. Output a shot list of about 5 images.
For each image, specify:
- Which paragraph it goes after
- Image theme
- Core meaning
- Structure type
- What ABIDEMI is doing
- Suggested elements
- Suggested short annotations

<paste article>
```

## Article Illustration

```text
Use $abidemi-illustrations to generate 4 quirky explanatory illustrations for this article.
Requirements: 16:9 landscape, pure white background, black hand-drawn line art, sparse red/orange/blue short annotations.
Each image explains one core structure. No PPT infographics, no cute cartoons.

<paste article>
```

## Long Article Strategy

```text
Use $abidemi-illustrations to create an illustration strategy for this long article.
Do not distribute images evenly. Only pick cognitive anchors: core judgments, input-output loops, before-after comparisons, common pitfalls, handoff paths.
Default 6-8 images. First output the shot list, do not generate images.

<paste article>
```

## Single Concept Image

```text
Use $abidemi-illustrations to generate a 16:9 illustration for this concept:

Trust is not shouted. It is laid down one piece of evidence at a time.

The scene should be quirky but clean. ABIDEMI must perform the core action.
Annotations: at most 5, keep them short.
```

## Workflow Theme

```text
Use $abidemi-illustrations to generate an image for "turning raw material into traffic, trust, and conversion - three types of content."
Do not draw a formal flowchart. Do not copy the one-fish-many-uses old case.
Please invent a new low-tech metaphor with ABIDEMI participating in the core action.
```

## Edit: Remove Title

```text
Use $abidemi-illustrations help me edit this image.
Remove the "Workflow / Flowchart" title and underline from the top-left corner. Keep everything else unchanged.
Do not add any new text or objects.
```

## Edit: Enhance ABIDEMI Participation

```text
Use $abidemi-illustrations this image is on the right track but ABIDEMI feels a bit like decoration.
Please keep the core meaning and regenerate: make ABIDEMI the one truly driving the structure.
Make it a bit stranger, but still pure white, clean, and with minimal text.
```

## Generate Style Samples

```text
Use $abidemi-illustrations output 5 illustration samples on different themes.
Themes: information overload, product validation, content compound interest, one-person company, trust building.
Generate each image individually, do not combine into one.
```
