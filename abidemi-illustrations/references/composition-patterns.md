# Composition Patterns and Originality Rules

## Basic Structure Types

Choose one structure. Do not mix too many.

### Workflow

Suitable for: Input -> Process -> Output, content production, AI workflows, automation chains.

Drawing method: Left side input, middle ABIDEMI or quirky machine processes, right side output, orange arrows show main flow direction.

### System Part

Suitable for: Information sources, filters, databases, renderers, agent system components.

Drawing method: Only draw 3-5 core modules. ABIDEMI participates in one key action.

### Before-After Comparison

Suitable for: Chaos/order, manual/automatic, scattered/gathered, anxious/stable.

Drawing method: Left side chaotic, right side stable, orange arrow in middle. Characters can be more exaggerated.

### Role State

Suitable for: User pain points, creator states, too many tools, information anxiety, stuck to running.

Drawing method: 2-4 small states, each state with one short annotation.

### Concept Metaphor

Suitable for: Content factory, information warehouse, brain black box, workflow machine, auto daily reports.

Drawing method: One large monster piece or machine, a few inputs, one output. Must have a memorable element.

### Method Layers

Suitable for: Methodology frameworks, system levels, capability stacks, content system layers.

Drawing method: Layered boxes, not formal pyramids. ABIDEMI beside building or assembling.

### Map Route

Suitable for: From idea to launch, user paths, content handoff paths, learning routes.

Drawing method: One winding path, a few nodes, ABIDEMI guiding lines or walking.

### Mini Comic Panels

Suitable for: Failure to success, real process, complaints, before-after changes.

Drawing method: 2-4 small scenes, each panel showing one action.

## Original Metaphor Generation

Each time invent a new metaphor from the current article. Do not copy old images.

### Three Steps

1. Replace the abstract concept with a physical action: stuck, missed, getting heavier, sorting, settling, fermenting, opening a door, folding, unwrapping, flowing back.
2. Replace the system structure with a low-tech object: broken machine, cardboard box, drawer, water pipe, mailbox, quirky dial, scale, well, ladder, strange workstation.
3. Give ABIDEMI the action: not standing beside, but stuck inside the machine, pulling the wrong wire, guarding the door, carrying, repairing, weighing, holding the ladder, recording, stuffing something into a strange device.

### Available Object Pool

- Cardboard boxes, drawers, old machines, funnels, scales, mailboxes, doors, wells, ladders, water pipes, string balls, gates, turntables, black boxes, hole punchers, pasta machines, clotheslines, strange workstations.
- When using, pick only 1-2, do not pile them up.

### ABIDEMI Action Pool

- Pull, carry, stuff, scoop, press, weigh, sew, cut, twist, guard, push, catch, dismantle, mark, recycle.
- Actions must serve the core meaning, not just be strange for the sake of it.

## Anti-Copycat Rules

Do not open or copy `assets/examples/` by default. These images are only for style calibration: line density, white space, color restraint, ABIDEMI character.

Unless the user explicitly says "copy this one / replicate this composition / modify using this case", do not directly reuse these old compositions:

- Conveyor belt with two breakpoints
- ABIDEMI pulling judgment lever inside a content machine
- ABIDEMI as funnel sorting traffic/trust/conversion
- ABIDEMI cutting material fish
- ABIDEMI guiding handoff path
- ABIDEMI pulling three-layer information sources
- Three ABIDEMI characters each holding megaphone/building bridge/opening door
- ABIDEMI stamping handoff script toolbox
- ABIDEMI holding signs looking at common pitfall paths

Even for similar themes, use new metaphors. For example, "handoff path" does not have to draw a route. You could draw ABIDEMI connecting a content tail to a door handle. "One-fish-many-uses" does not have to draw a fish. You could draw ABIDEMI pressing a paper ball into several shapes.
